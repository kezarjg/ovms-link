# ABRP 3.0.0 SP1 / WS1 — Module Split + Bundler — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Refactor the single-file `lib/abrp.js` into focused `lib/abrp/*` CommonJS modules and add a dependency-free bundler that emits one Duktape-safe `dist/abrp.js` — with **no behavior change** (the existing test suite passes against the bundle).

**Architecture:** Modules use native relative `require('./x')`. A custom Node `build.js` concatenates them (resolving requires at build time) into `dist/abrp.js`, which becomes the single plugin deliverable. Each module owns its mutable state and exposes accessor functions (extending the existing `__test` seam pattern); no shared/global state. The existing Jest suite is repointed at the **bundle** as the regression harness, so every extraction step stays green.

**Tech Stack:** JavaScript (ES2015 / Duktape-safe — `var`/`function` only, no arrows/templates/spread in `lib/abrp/*` or the emitted bundle), Node 18, Jest 28, ESLint 8.

**Spec:** `docs/superpowers/specs/2026-06-02-abrp-3.0.0-sp1-design.md` (WS1 section).

## Conventions

- **Duktape-safe source:** every file under `lib/abrp/` uses `var` + `function` only. No arrow functions, template literals, object spread. (Jest test files may use modern JS.)
- **Verbatim moves:** several steps say "move function `X` from the current `lib/abrp.js`." That means relocate the **existing body unchanged**; only the wiring (requires, `module.exports`, replacing direct cross-module state access with accessor calls) is new and is shown in full.
- **Green at every step:** after each extraction, `npm run build` then `npm test` must pass (the suite runs against `dist/abrp.js`). Commit only when green.
- **Module ownership of state:** the module that declares a piece of mutable state is the only one that mutates it; other modules use its exported accessors.

- [ ] **Step 3: Implement `build.js`**

Create `build.js`:
```javascript
// Dependency-free CommonJS bundler for the OVMS/Duktape deliverable.
// Concatenates lib/abrp/*.js modules (relative requires resolved here) into one
// self-contained, Duktape-safe file. Usage:
//   node build.js --src lib/abrp --entry abrp --out dist/abrp.js
var fs = require('fs')
var path = require('path')

function arg(name, def) {
  var i = process.argv.indexOf('--' + name)
  return i !== -1 ? process.argv[i + 1] : def
}

var srcDir = path.resolve(arg('src', 'lib/abrp'))
var entry = arg('entry', 'abrp')
var outFile = path.resolve(arg('out', 'dist/abrp.js'))

// Normalize a require id to a bare module name (all modules live in one dir).
function norm(id) {
  return id.replace(/^\.\//, '').replace(/\.js$/, '')
}

// Collect every .js module in the source dir (excluding *.test.js).
var modules = {}
fs.readdirSync(srcDir).forEach(function (f) {
  if (/\.js$/.test(f) && !/\.test\.js$/.test(f)) {
    modules[norm(f)] = fs.readFileSync(path.join(srcDir, f), 'utf8')
  }
})

// Emit: a tiny CommonJS registry + each module as a factory + the entry export.
var out = []
out.push('// GENERATED by build.js — do not edit. Source: lib/abrp/*.js')
out.push('(function () {')
out.push('  var __mods = {};')
out.push('  var __cache = {};')
out.push('  function __require(id) {')
out.push('    id = id.replace(/^\\.\\//, "").replace(/\\.js$/, "");')
out.push('    if (__cache[id]) { return __cache[id].exports; }')
out.push('    var m = { exports: {} };')
out.push('    __cache[id] = m;')
out.push('    __mods[id](m, m.exports, __require);')
out.push('    return m.exports;')
out.push('  }')
Object.keys(modules).forEach(function (name) {
  out.push('  __mods[' + JSON.stringify(name) + '] = function (module, exports, require) {')
  out.push(modules[name])
  out.push('  };')
})
out.push('  module.exports = __require(' + JSON.stringify(entry) + ');')
out.push('})();')
var bundle = out.join('\n') + '\n'

// Duktape-safety guard on the emitted file (ignore comment lines).
var offenders = bundle.split('\n').filter(function (line) {
  var code = line.replace(/\/\/.*$/, '')
  return /=>/.test(code) || /`/.test(code)
})
if (offenders.length) {
  console.error('build.js: Duktape-unsafe syntax in bundle:\n' + offenders.join('\n'))
  process.exit(1)
}

fs.mkdirSync(path.dirname(outFile), { recursive: true })
fs.writeFileSync(outFile, bundle)
console.log('build.js: wrote ' + outFile + ' (' + bundle.length + ' bytes, ' + Object.keys(modules).length + ' modules)')
```
