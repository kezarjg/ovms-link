# WS3 CA-certificate Bootstrap Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** At first plugin run, automatically write the curated CA roots into `/store/trustedca` and run `tls trust reload`, so TLS to `api.iternio.com` works without the manual certificate step.

**Architecture:** A bundled logic module (`lib/abrp/certs.js`) runs from `events.js` `startup()`, gated by a config version stamp (`usr abrp.certs_version` vs a baked `CERTS_VERSION`). The cert bytes ship as a **separate** `module` plugin element (`certdata.js`, generated by `publish.js` from `trustedca/*.pem`) and are read at runtime via the host `require`. Because the bundle's internal `__require` only knows bundled modules, `build.js` is taught to defer unknown require ids to the host `require`.

**Tech Stack:** CommonJS modules targeting OVMS Duktape (ES2015, `var` + string concat, no arrow functions / template literals in `lib/abrp/*` or emitted bundle). Node 22 `node:test` + `node:assert` against the built bundle and source modules. Node-side tooling: `build.js`, `publish.js`.

**Reference spec:** `docs/superpowers/specs/2026-06-06-ws3-cert-bootstrap-design.md`

---

## Background the implementer needs

- **The bundler.** `build.js` concatenates `lib/abrp/*.js` into `dist/abrp.js`. Inside the bundle, every `require(...)` call from a module routes through a tiny internal `__require` that looks the id up in a registry of bundled modules. It currently has **no fallback**, so an id it doesn't know (e.g. `plugin/abrp/certdata`, which is intentionally NOT bundled) makes `__mods[id]` `undefined` and the call throws. Task 1 fixes this so unknown ids defer to the real (host/OVMS) `require`.
- **OVMS host globals** (`VFS`, `OvmsConfig`, `OvmsCommand`, …) are injected by the device, not imported. Off-device they're `undefined` unless a test sets them on `global`. They must be declared in `.eslintrc.json` `globals` or ESLint flags `no-undef`.
- **`VFS.Save({path, data, done, fail})`** is asynchronous: `done()` on success, `fail(err)` on error. **`OvmsCommand.Exec("tls trust reload")`** runs an OVMS CLI command. Exact signatures are an on-device-verify item (§"On-device validation"); unit tests stub both.
- **Test layout.** Per-module tests (`lib/abrp/*.test.js`) `require()` the source module directly; the main suite (`lib/abrp.test.js`) tests the built bundle. Node-side tooling tests live in `test/` (`test/build.test.js`, `test/publish.test.js`). The `npm test` script lists each test file explicitly — new files must be added there.
- **Module style.** Match the existing `var` + `function` + string-concatenation style. No arrow functions or template literals in `lib/abrp/*` or `publish.js`-emitted Duktape code.

- [ ] **Step 4: Implement `lib/abrp/certs.js`**

Create `lib/abrp/certs.js`. Note the self-guard (makes it a safe no-op off-device and unit-testable), the injectable loader (so tests don't resolve the external element), and the async fan-in via a plain counter:

```js
// CA-certificate bootstrap: at first run, write the curated CA roots into
// /store/trustedca and run `tls trust reload`, gated by a config version stamp.
// Owns its own one-time state. Self-guards to a no-op when the host file/command
// APIs are absent (off-device, hand-install). Carries no PEM bytes — the cert
// data ships as a separate plugin element loaded via the host require.
var C = require('./constants')
var U = require('./util')
var Logger = U.Logger

// True only while an install is mid-flight, to guard against re-entry.
var inProgress = false

// Indirection so unit tests can inject fake cert data without resolving the
// external module. On-device this reaches the second plugin element through the
// host require (build.js defers unknown ids to it).
function defaultLoader() {
  return require('plugin/abrp/certdata')
}
var certDataLoader = defaultLoader

function setCertDataLoader(fn) {
  certDataLoader = fn
}

function bootstrap() {
  if (typeof VFS === 'undefined' ||
      typeof OvmsConfig === 'undefined' ||
      typeof OvmsCommand === 'undefined') {
    return // host APIs unavailable (off-device / hand-install)
  }
  if (inProgress) {
    return
  }

  var stamp = Number(OvmsConfig.Get('usr', 'abrp.certs_version', '0'));
  if (stamp >= C.CERTS_VERSION) {
    return // up to date — zero I/O
  }

  var certs;
  try {
    certs = certDataLoader();
  } catch (e) {
    Logger.error('Cert bootstrap: cert data unavailable (' + e + ')');
    return;
  }
  if (!certs || !certs.length) {
    Logger.error('Cert bootstrap: cert data empty');
    return;
  }

  inProgress = true;
  var total = certs.length;
  var settled = 0;
  var failed = false;

  function settle() {
    settled += 1;
    if (settled < total) {
      return;
    }
    inProgress = false;
    if (failed) {
      Logger.error('Cert bootstrap: a cert failed to write; will retry next start');
      return;
    }
    try {
      OvmsCommand.Exec('tls trust reload');
    } catch (e2) {
      Logger.error('Cert bootstrap: tls trust reload failed (' + e2 + ')');
      return;
    }
    OvmsConfig.Set('usr', 'abrp.certs_version', String(C.CERTS_VERSION));
    Logger.info('Cert bootstrap: installed ' + total + ' CA root(s)');
  }

  certs.forEach(function (cert) {
    VFS.Save({
      path: '/store/trustedca/' + cert.file,
      data: cert.pem,
      done: function () {
        settle();
      },
      fail: function (err) {
        failed = true;
        Logger.error('Cert bootstrap: failed to write ' + cert.file + ' (' + err + ')');
        settle();
      },
    });
  });
}

module.exports = {
  bootstrap: bootstrap,
  __test: {
    setCertDataLoader: setCertDataLoader,
  },
};
```

// Reads the CA roots from certDir into [{file, pem}] entries (skips non-cert
// files like README.md). These ship as a separate plugin element.
function buildCertData(certDir) {
  return fs
    .readdirSync(certDir)
    .filter(function (f) {
      return /\.(pem|crt)$/.test(f)
    })
    .map(function (f) {
      return { file: f, pem: fs.readFileSync(path.join(certDir, f), 'utf8') }
    })
}

// Renders the cert entries as a Duktape-safe CommonJS module. JSON.stringify
// produces a plain object/array literal (no template literals / arrow functions)

function assemblePages(outDir, bundlePath, version, certDir) {
  certDir = certDir || path.resolve(__dirname, 'trustedca')
  var pluginDir = path.join(outDir, 'abrp')
  var manifestPath = path.join(outDir, 'plugins.json')
